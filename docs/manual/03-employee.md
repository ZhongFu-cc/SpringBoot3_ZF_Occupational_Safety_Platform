# 企業員工（學員）使用說明手冊

> 適用對象：接受職安教育訓練的公司同仁

---

## 一、你可以做什麼

1. 查看公司指派給你的課程
2. 觀看課程影片、累積學習時數
3. 通過課後總測驗，取得完課認證
4. 查看與下載自己的學習歷程

你只看得到自己的資料。

---

## 二、上課流程

```
登入
 └─ 我的課程 → 挑一門課進入
      └─ 依序點開章節觀看
           （系統自動累積你的學習時數）
      └─ 所有章節看完 + 時數達標
           └─ 總測驗解鎖 → 作答 → 全部答對即完課
                └─ 取得完課認證（效期一年）
```

---

### 步驟 1：登入

用公司承辦人給你的帳號密碼登入。

- 系統**沒有自行註冊**的功能，帳號一律由公司承辦人建立。
- 系統**沒有忘記密碼**的功能。忘記密碼或登不進去，請找公司的教育訓練承辦人重設。
- 如果帳號被停用，也會登不進去，同樣請找承辦人。

### 步驟 2：查看我的課程

登入後可以看到公司指派給你的課程，每門課會顯示目前狀態：

| 狀態 | 意思 |
| --- | --- |
| 未開始 | 已指派但你還沒點過任何章節 |
| 進行中 | 你已經開始上課了 |
| 已完成 | 通過總測驗，取得認證 |
| 已被取消 | 報名已取消 |

另外有兩個地方可以看整體狀況：

- **學習歷程總覽** — 一次看到總課程數、已完成數、即將到期提醒等
- **學習歷程明細** — 可翻頁、可用課程名稱搜尋的完整清單

⚠️ 如果「我的課程」是空的，表示你的部門還沒被配課，或承辦人還沒幫你開課。請聯絡公司承辦人。

### 步驟 3：進入課程、觀看章節

點進課程後會看到章節目錄（可能有大單元、小單元的層次），依序點開觀看即可。

**關於學習時數（重要）：**

- 系統在你觀看時會**自動、持續地記錄學習時間**，你不需要做任何事。
- **每一門課都有規定的應修時數**，時數不夠就無法進行總測驗。
- 時數的計算有防呆機制：把頁面開著放整晚**不會**灌到時數，必須實際停留在學習頁面才算。
- **離開時請正常操作** —— 切換到別的章節、或按離開／返回。這樣系統才能立刻結算你的學習時間。

  如果你直接關掉瀏覽器分頁，系統仍然會補算，只是不會馬上反映。**剛看完課馬上去查時數還沒更新，是正常的，稍等一下再看。**

- 建議不要同時開好幾個分頁上不同的課，時數計算會不準確。

### 步驟 4：進行總測驗

課程的最後一章通常是「總測驗」。

**要解鎖測驗，你必須同時滿足三個條件：**

1. 課程狀態是「進行中」
2. **累積學習時數已經達到課程規定的時數**
3. 除了測驗以外的所有章節都已經看過

只要有一項沒達成，點測驗時會看到「**尚未達成測驗的條件**」。**最常見的原因是時數還不夠**，請回去把影片實際看完。

**測驗規則：**

| 項目 | 說明 |
| --- | --- |
| 題數 | 從題庫**隨機抽 10 題**，每次抽到的題目不一定相同，選項順序也會打亂 |
| 及格標準 | **必須 10 題全部答對** 才算通過 |
| 答錯的話 | 系統會記下你這次的分數，章節維持「進行中」，**可以重考** |
| 重考次數 | **沒有限制**，可以一直重考到通過為止 |

**作答完會顯示每一題的檢討**：題目、正確答案、你的答案、是否答對。答錯時請仔細看檢討內容，再回去複習相關章節。

### 步驟 5：完課與認證

通過總測驗的當下，系統會：

1. 把這門課標記為「已完成」
2. 記錄你的完成時間
3. **發給效期一年的完課認證**

你可以隨時**下載自己的學習歷程**（Excel 檔），內含你所有的修課紀錄，可以自行留存。

---

## 三、注意事項

**一定要實際看完影片**

只是把章節點開就跳過，雖然章節會被標記成看過，但**學習時數不會累積**，最後還是會卡在測驗解鎖那一關。與其反覆卡關，不如一次好好看完。

**測驗答錯不用緊張**

可以無限次重考，每次重新隨機抽題。答錯不會有任何懲罰，也不會記在什麼地方影響你，系統只是記錄你考了幾次。

**認證效期一年**

完課認證的效期是一年。到期後依規定需要複訓，但**目前系統不會主動提醒你，也不會自動幫你重新開課**（見下方已知問題）。如果你需要有效的訓練證明，請自行留意完課日期，或直接詢問公司承辦人。

**帳號問題找承辦人**

忘記密碼、帳號被停用、課程列表是空的、課程指派錯了 —— 這些都請聯絡公司的教育訓練承辦人處理，系統沒有讓你自助處理的功能。

## 四、目前已知問題

### 🔴 認證過期不會自動提醒，也不會自動重新開課

**現象**：完課認證的效期是一年，但系統目前不會在到期後把課程狀態改成「已過期」，畫面上會一直顯示「已完成」。承辦人的一鍵報名功能也不會幫證書過期的人重新開課。

**對你的影響**：你可能以為自己的訓練還有效，實際上證書早就過期了。

**建議做法**：自己記下每門課的完課日期。滿一年前主動詢問公司承辦人是否需要複訓，不要等系統通知。

---

### 🔴 用 Excel 批次建立的帳號，登入後可能看不到選單

**現象**：如果你的帳號是承辦人用 Excel 批次匯入建立的，可能因為系統的問題沒有被賦予角色，導致**登入成功但畫面上沒有任何功能選單**。

**對你的影響**：帳號密碼都對，也登得進去，但什麼都做不了。

**建議做法**：這不是你操作錯誤，請直接聯絡公司承辦人，說明「登入後看不到選單」，由承辦人聯絡系統維護方處理。

---

### 🟠 用 Excel 批次建立的帳號，「我的課程」可能是空的

**現象**：同樣是批次匯入的問題，這類帳號不會自動拿到部門課程。

**建議做法**：聯絡公司承辦人，請他執行一次「一鍵報名」，你的課程就會出現。

---

### 🟠 有些課程可能永遠解不開測驗

**現象**：如果課程本身設計有問題（例如放了兩個測驗章節），測驗的解鎖條件會永遠湊不齊。

**判斷方式**：你確定所有章節都看完了、時數也顯示足夠了，但點測驗仍然一直顯示「尚未達成測驗的條件」。

**建議做法**：不要再反覆嘗試，直接聯絡公司承辦人回報，由承辦人向平台方確認課程設定。

---

### 🟡 測驗必須全部答對才能通過

**現象**：目前沒有及格分數線（例如 80 分及格）的設計，10 題必須全對。

**對你的影響**：可能需要考好幾次才會過。

**建議做法**：這是系統目前的規則，不是你的問題。答錯後請仔細看題目檢討，回去複習後再考，重考次數沒有限制。
