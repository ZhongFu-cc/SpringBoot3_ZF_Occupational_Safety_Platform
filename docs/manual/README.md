## 三個角色的關係

```
平台管理者
   │  製作課程內容、建立公司、開通企業管理者帳號
   ▼
企業管理者   ← 只能管理自己公司的資料
   │  建立部門、配課、建立員工帳號、追蹤進度
   ▼
企業員工     ← 只能看到自己的資料
      上課 → 測驗 → 取得完課認證（效期一年）
```

**權限是嚴格隔離的**：企業管理者看不到別家公司的任何資料，員工也只看得到自己的學習紀錄。系統在每一個動作都會再檢查一次，不是只把按鈕藏起來而已。

## 完整導入流程（跨角色全貌）

| 階段 | 誰做 | 做什麼 |
| --- | --- | --- |
| 1 | 平台管理者 | 建立作業類別（高架作業、局限空間作業…） |
| 2 | 平台管理者 | 建立課程類別 → 課程 → 章節 → 上傳影片 |
| 3 | 平台管理者 | 建立測驗題庫，掛到測驗章節上 |
| 4 | 平台管理者 | 設定「哪個作業類別要上哪些課」，並標記必修 |
| 5 | 平台管理者 | 建立公司，勾選該公司適用的作業類別（系統自動把必修課放進該公司課程庫） |
| 6 | 平台管理者 | 建立該公司的企業管理者帳號 |
| 7 | 企業管理者 | 建立部門 |
| 8 | 企業管理者 | 從公司課程庫挑課，指派給部門 |
| 9 | 企業管理者 | 建立員工帳號（單筆或 Excel 批次） |
| 10 | 企業管理者 | 執行「一鍵報名」，讓既有員工也拿到課程 |
| 11 | 員工 | 上課 → 累積時數 → 通過總測驗 → 取得認證 |
| 12 | 企業管理者 | 用進度統計追蹤，年底出 ESG 報表 |

## 通用注意事項

**帳號與密碼**

- 三個角色都用同一個登入入口，系統會依你的角色自動顯示對應的功能選單。
- 帳號由上一層建立：企業管理者的帳號由平台管理者開，員工的帳號由企業管理者開。**沒有自行註冊的功能**。
- 目前**沒有忘記密碼、自助改密碼的功能**。忘記密碼請找上一層的管理者重設。

**停用 vs 刪除**

- 停用：帳號無法登入，但資料與學習紀錄都保留。
- 刪除：資料移除，不可復原。
- **人員異動一律建議用「停用」**。刪除後那個人的訓練紀錄就查不到了，ESG 稽核或勞檢時會有麻煩。

**狀態名詞對照**

| 課程狀態 | 意思 |
| --- | --- |
| 未開始 | 已報名但還沒點過任何章節 |
| 進行中 | 已經開始上課 |
| 已完成 | 通過總測驗，取得認證 |
| 已過期 | 認證超過一年效期（**注意：目前系統不會自動變成這個狀態，見下方 Bug 清單**） |
| 已被取消 | 報名被取消 |

## 目前已知問題總表

以下都是已從程式碼確認的問題，各手冊內會再說明對該角色的具體影響與暫時做法。

| # | 問題 | 嚴重度 | 影響對象 |
| --- | --- | --- | --- |
| 1 | **年度複訓無法自動啟動** — 認證過期的員工不會被「一鍵報名」重新開課，狀態也不會變成「已過期」 | 🔴 高 | 企業管理者、員工 |
| 2 | **Excel 匯入的員工沒有被賦予角色** — 可以登入，但登入後看不到功能選單 | 🔴 高 | 企業管理者 |
| 3 | **Excel 匯入的員工不會自動拿到課程** — 需另外手動執行一鍵報名 | 🟠 中 | 企業管理者 |
| 4 | **題庫與正確答案沒有權限保護** — 未登入者也能查看甚至修改題目與答案 | 🔴 高（資安） | 平台管理者 |
| 5 | **公司的自動配課只在建立公司當下執行一次** — 事後調整必修設定不會回補到既有公司 | 🟠 中 | 平台管理者 |
| 6 | **課程「總時數」沒填會讓學員報名時失敗** | 🟠 中 | 平台管理者 |
| 7 | **一門課有兩個以上測驗章節時，學員將永遠解鎖不了測驗** | 🟠 中 | 平台管理者、員工 |
| 8 | **總測驗必須全部答對才算通過**，沒有及格分數線可設定 | 🟡 低（設計限制） | 員工、平台管理者 |
